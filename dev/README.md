# סופר-לי - מודול מלאי + ספקים (חלק תכנותי)

## מגישים

יונתן בר 209805944, ניר יטח 322919663

המודול הזה (ניהול מלאי + ספקים) הוא החלק שלנו במערכת המאוחדת של הרביעייה, והוא משולב בהגשה זו עם מודול עובדים + הובלות (אוריאן בוקריס 329353346, הראל דוד 216265777) למערכת אחת מעל בסיס נתונים אחד משותף. מתחברים לפי ת"ז של עובד, ולפי תפקיד העובד נפתח התפריט המתאים: מחסנאי מקבל את תפריט המלאי, מנהל משמרת את תפריט ניהול העובדים והמשמרות, וכל עובד את תפריט העובד.

## הרצה

הדרך הפשוטה, מתוך תיקיית `release/`:

```
java -jar adss2025_v02.jar
```

ה-jar כולל בתוכו את מנוע ה-SQLite, כך שאין צורך להתקין שום ספרייה נוספת. בהרצה הראשונה נטענים אוטומטית נתוני הדוגמה (עובדים, ספקים ומלאי) לבסיס הנתונים. אפשר להתחבר למשל עם ת"ז 222 (מחסנאי, פותח את תפריט המלאי) או 333 (מנהל משמרת, פותח את תפריט העובדים והמשמרות).

## בנייה מחדש מהמקור

מתוך תיקיית `dev/`:

```
javac --release 17 -cp lib/sqlite-jdbc-3.46.1.3.jar -d out $(find src -name "*.java" ! -path "*/tests/*")
java -cp out:lib/sqlite-jdbc-3.46.1.3.jar Inventory.Main
```

הרצת הטסטים:

```
javac -cp out:lib/junit-platform-console-standalone.jar:lib/sqlite-jdbc-3.46.1.3.jar -d out src/tests/*.java
java -cp out:lib/junit-platform-console-standalone.jar:lib/sqlite-jdbc-3.46.1.3.jar \
  org.junit.platform.console.ConsoleLauncher execute --select-package=tests
```

## ספריות בשימוש

- `sqlite-jdbc-3.46.1.3.jar` - מנוע בסיס הנתונים SQLite (דרך JDBC).
- `junit-platform-console-standalone.jar` - הרצת בדיקות היחידה.

## בסיס הנתונים

כל נתוני המערכת המאוחדת נשמרים מקומית בקובץ `superLee.db` (SQLite) אחד, המשותף לשני המודולים ונוצר אוטומטית בהרצה הראשונה בתיקיית העבודה.

טבלאות מודול מלאי + ספקים:

| טבלה | תפקיד |
|------|-------|
| `categories` | קטגוריות בהיררכיה (parent_category_id = 0 לקטגוריית שורש) |
| `product_specs` | פרטי המוצרים (שם, יצרן, קטגוריה, מחירים, סף מינימום, כמות כוללת) |
| `products` | מופע פיזי לכל יחידת מלאי (product_id, spec_id) |
| `stock_items` | מלאי לפי מיקום (חנות/מחסן, מדף, שורה, כמות, תוקף) |
| `stock_item_products` | שיוך בין כל יחידה פיזית למיקום המלאי שבו היא נמצאת |
| `promotions` | מבצעים (אחוז הנחה, טווח תאריכים, יעד מוצר או קטגוריה) |
| `defective_reports` | דיווחי פגמים (מזהה מוצר, כמות, סיבה, תאריך) |

טבלאות מודול עובדים + הובלות:

| טבלה | תפקיד |
|------|-------|
| `employees` | פרטי העובדים (ת"ז, שם, תנאי העסקה) |
| `employee_roles` | התפקידים של כל עובד |
| `employee_availabilities` | זמינות העובד לפי יום ומשמרת |
| `shifts` | משמרות לפי יום וסוג משמרת |
| `shift_requirements` | דרישות התפקידים לכל משמרת (כמה עובדים מכל תפקיד) |
| `shift_assignments` | שיבוץ העובדים בפועל למשמרות |

הקובץ `superLee.db` אינו נשמר ב-git (הוא נוצר מחדש בכל הרצה).

## נתוני דוגמה

בטעינת נתוני הדוגמה נטענים: 9 קטגוריות בשלוש היררכיות, 5 מוצרים, מלאי בחנות ובמחסן לכל מוצר, מבצע אחד, ודיווח פגם אחד. בנוסף נטענים 10 עובדים בתפקידים שונים (מחסנאי, קופאי, נהג ומנהל משמרת), כולל כמה עובדים באותו תפקיד עם זמינויות שונות, וכן מספר משמרות עם דרישות תפקיד ושיבוצים לדוגמה. הנתונים מאפשרים לבדוק את כל פעולות המערכת מהתפריט (מלאי, ספקים, עובדים ומשמרות).

## מודול הספקים

נתוני הספקים (ספקים, הסכמי הספקה ולוחות זמנים) הם נתוני mock בקוד ואינם נשמרים ב-DB. מודול הספקים באיטרציה זו הוא דמה (mock) לצורך הדגמת תהליך הוצאת ההזמנה, ולכן אין לו שכבת DAO/טבלאות משלו.

בהפעלה נטענים אוטומטית 3 ספקים: ACME Supplies (1), Global Foods (2) ו-Fresh Market (3). שלושתם מספקים את אותו מוצר חסר במלאי, Bissli 70g (specId 5), במחירים שונים: 3.50, 3.20 ו-3.35 ליחידה בהתאמה. כך הזמנה עקב חוסר (אופציה 16) בוחרת אוטומטית את הספק הזול ביותר (Global Foods, 3.20). לכל ספק גם לוח זמני אספקה קבוע (רביעי/שני/חמישי), כדי להדגים הזמנה תקופתית (אופציה 17).
