# תיאור כללי

 המערכת היא מערכת ניהול משולבת עבור רשת סופר-לי, המאוחדת ממספר מודולים. הזוג שלנו אחראי על שני המודולים הבאים:



 מודול עובדים - ניהול רשימת עובדים, מעקב אחר זמינויות ואילוצים, הגדרת תפקידים והסמכות, קביעת דרישות תפקיד לכל משמרת (כמות מכל תפקיד), ושיבוץ עובדים למשמרות (כולל אפשרות לשיבוץ חריג באישור מנהל).

 
 מודול הובלות  - רישום נהגים כחלק מצוות העובדים, מעקב אחר סוגי רישיונות נהיגה, וניהול תקינות קבלת הובלות לסניף במועדים השונים.


 שני המודולים עובדים יחד: כאשר נקבעת הובלה לסניף, המערכת מסתנכרנת עם מודול העובדים כדי לוודא שמשובץ לאותה משמרת נהג פעיל עם רישיון תואם ועובד בתפקיד מחסנאי שיקבל את הסחורה. מערכת ההובלות החיצונית ממומשת כ-mock (DeliveryServiceMock).
