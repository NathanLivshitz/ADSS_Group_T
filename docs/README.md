## תיאור כללי

המערכת היא מערכת ניהול משולבת עבור רשת סופר-לי, המאוחדת ממספר מודולים. הזוג שלנו אחראי על שני המודולים הבאים:

- **מודול ניהול מלאי (Inventory)** - ניהול קטלוג מוצרים, מעקב כמויות בחנות ובמחסן, ספי מינימום והתראות חוסר, קטגוריות, מבצעים, ודיווח פגמים.
- **מודול ספקים (Suppliers)** - ניהול ספקים והסכמי הספקה (כתבי כמויות), הוצאת הזמנות (תקופתיות ועקב חוסר), ובחירת הספק המשתלם ביותר לכל הזמנה.

שני המודולים עובדים יחד: כאשר מלאי מוצר יורד מתחת לסף המינימום, המערכת מאתרת את הספקים מתוך הסכמי ההספקה, בוחרת את המחיר המשתלם, ומוציאה הזמנה. מערכת הספקים החיצונית ממומשת באיטרציה זו כ-mock. שכבת הנתונים בנויה בתבנית Repository + DAO + DTO מעל SQLite.
