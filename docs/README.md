## תיאור כללי

מערכת ניהול משולבת עבור רשת סופר-לי. עד למטלה זו כל זוג פיתח שתי תת-מערכות בנפרד, וכעת אוחדו ארבעת המודולים למערכת אחת הפועלת מעל בסיס נתונים יחיד ומשותף (SQLite). המערכת מורכבת מארבעת המודולים הבאים:

### מודול מלאי + ספקים (יונתן בר, ניר יטח)

ניהול קטלוג מוצרים לפי היררכיית קטגוריות, מעקב אחר כמויות בחנות ובמחסן וסף מינימום לכל מוצר, ניהול מבצעים ודיווח על פריטים פגומים או פגי תוקף. בנוסף, המערכת מוציאה הזמנות מספק באופן אוטומטי בשני מקרים: הזמנה עקב חוסר (כאשר מלאי מוצר יורד מתחת לסף המינימום) והזמנה תקופתית בימי הספקה קבועים. כאשר מוצר מסופק על ידי יותר מספק אחד, המערכת בוחרת את הספק המשתלם ביותר לפי כתבי הכמויות. מערכת הספקים החיצונית ממומשת כ-mock.

### מודול עובדים + הובלות (אוריאן בוקריס, הראל דוד)

ניהול רשימת עובדים, תפקידים, זמינויות ואילוצים, ושיבוץ עובדים למשמרות לפי דרישות התפקיד (כולל אפשרות לשיבוץ חריג באישור מנהל). בנוסף, ניהול הובלות: רישום נהגים כחלק מצוות העובדים, מעקב אחר סוגי רישיונות נהיגה, ושיבוץ נהג בעל רישיון תואם לסוג המשאית עבור כל הובלה. מערכת ההובלות החיצונית ממומשת כ-mock.

### חיבור בין ארבעת המודולים

ארבעת המודולים פועלים כמערכת אחת מאוחדת מעל בסיס נתונים משותף. עם הוצאת הזמנה מספק (מודול ספקים), המערכת מתאמת הובלה למועד הגעת הסחורה (מודול הובלות). לכל הובלה משובץ נהג בעל רישיון מתאים, והמערכת מוודאת ששובץ מחסנאי זמין (מודול עובדים) במשמרת שבה צפויה ההגעה, כדי לקבל את הסחורה ולעדכן את רמת המלאי (מודול מלאי). כך, פעולה במודול אחד (הזמנה מספק) מפעילה תיאום אוטומטי על פני שלושת המודולים האחרים.
