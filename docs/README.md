## תיאור כללי

מערכת ניהול משולבת עבור רשת סופר-לי, המאוחדת מארבעה מודולים מעל בסיס נתונים אחד משותף:

- **מודול מלאי + ספקים** (יונתן בר, ניר יטח): ניהול קטלוג מוצרים, מעקב כמויות וספי מינימום, קטגוריות ומבצעים, והוצאת הזמנות מספק (עקב חוסר או תקופתית) תוך בחירת הספק המשתלם ביותר לפי כתבי הכמויות.
- **מודול עובדים + הובלות** (אוריאן בוקריס, הראל דוד): ניהול עובדים, זמינויות ותפקידים, שיבוץ למשמרות, וניהול הובלות עם שיבוץ נהג בעל רישיון תואם לסוג המשאית.

### חיבור בין ארבעת המודולים

עם הוצאת הזמנה מספק (מודול ספקים), המערכת מתאמת הובלה למועד הגעת הסחורה (מודול הובלות). לכל הובלה משובץ נהג בעל רישיון מתאים, והמערכת מוודאת ששובץ מחסנאי זמין (מודול עובדים) במשמרת שבה צפויה ההגעה כדי לקבל את הסחורה ולעדכן את המלאי (מודול מלאי). כך ארבעת המודולים פועלים יחד כמערכת אחת מאוחדת.
